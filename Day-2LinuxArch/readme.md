LINUX ARCHITECTURE

Linux architecture shows how the operating system works internally.

Basic Structure:

User → Shell → Kernel → Hardware

1. User

* The person who uses the system
* Gives commands or uses applications

2. Shell

* Command interpreter
* Takes user commands and sends them to kernel
* Example: bash

3. Kernel

* Core (brain) of Linux
* Manages:

  * CPU
  * Memory
  * Devices
  * Processes
  * File system

4. Hardware

* Physical components:

  * CPU
  * RAM
  * Disk
  * Keyboard

Working Flow:

User → enters command
Shell → interprets command
Kernel → processes request
Hardware → executes
Output → shown to user

Example:

Command: ls

* Shell reads command
* Kernel gets file list
* Output displayed

Summary:

User → Shell → Kernel → Hardware

Kernel = most important part of Linux
