3. Basic networking idea

An IP address (Internet Protocol address) is like a unique number for a device on a network.

👉 Think of it like a phone number or house address
It helps devices find each other.

📌 Example:
192.168.1.1

💡 Simple idea:
Every device (laptop, phone, server) has an IP
It is used to send and receive data

🌍 2. What is the Internet?

The internet is a global network of connected computers.

👉 It connects:

Phones
Laptops
Servers
Websites

💡 Simple idea:
Internet = “network of networks”
It allows communication between devices worldwide
🔗 How they work together

When you open a website:

You type: google.com
It converts to an IP address (like 142.250.xxx.xxx)
Your system connects to that IP
Website loads



🧠 Easy real-life example
IP address = house address
Internet = road network
