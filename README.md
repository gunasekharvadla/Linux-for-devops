# 🐧 Linux Fundamentals – Learning & Practice Repository

A structured hands-on repository documenting my Linux learning journey, focusing on **system administration, DevOps fundamentals, and real-world command-line usage**.

---

## 🚀 Objective

The goal of this repository is to build strong expertise in Linux by practicing:
- System navigation and file management
- User and permission control
- Process and service management
- Networking fundamentals
- Shell scripting and automation

This serves as a foundation for **DevOps, Cloud, and Site Reliability Engineering roles**.

---

## 🧰 Technologies & Tools

- Linux (Ubuntu / CentOS)
- Bash Shell
- Terminal CLI
- Basic scripting (Bash)
- System utilities
